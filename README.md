**Quentis RP** — український Role-Play проєкт на базі **Grand Theft Auto IV та IV:MP**.

> 🎮 Role-Play • 🚔 Фракції • 🏎️ Дрифт • 🌆 Liberty City • 👥 Multiplayer

## 🎮 Про проєкт

Quentis RP — це мультиплеєрний проєкт для GTA IV, створений для української спільноти.

На сервері можна:

- 🚔 вступати до фракцій;
- 👨‍⚕️ працювати та розвивати персонажа;
- 🚗 купувати автомобілі;
- 🏎️ брати участь у дрифт-заїздах;
- 💼 розвивати власний бізнес;
- 🎭 грати за правилами Role-Play;
- 🎉 брати участь у серверних івентах;
- 👥 спілкуватися з іншими гравцями.
